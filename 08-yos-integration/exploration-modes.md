# Exploration modes (draft, from FiF)

**Status:** DRAFT reading template, not canon. **Provenance:** FiF prototype spec (January 2026), "5 Exploration Modes".

Any chapter or domain can be read in five modes. They can serve as a reading guide for the foundation chapters (P03–P09).

| Mode | What it does | Tone | Output |
|---|---|---|---|
| **Deep Dive** | Technical depth within one domain | Detailed, comprehensive | Long-form explanation with examples |
| **Systems Weave** | Cross-domain connections and cascading effects | Relational | How this domain affects / is affected by the others |
| **Essential Insight** | Distilled key takeaways (5-minute read) | Concise, memorable | Core concepts as bullets with one-liners |
| **Strategic Questions** | Personal and societal implications to consider | Socratic, provocative | Questions to reflect on, scenarios to consider |
| **Action Gateway** | How to position yourself, skills to build | Practical | Concrete actions, resources, learning paths |

## Chapter template
For each foundation chapter, an optional appendix block:
1. Essential Insight — 5 bullets.
2. Systems Weave — 3 links to other foundations ("This connects to … which has implications for …").
3. Strategic Questions — 5 questions.
4. Action Gateway — 3 actions.
